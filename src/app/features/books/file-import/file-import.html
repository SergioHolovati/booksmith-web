De onde vem o arquivo:

  • Word: o próprio .docx (se for .doc antigo, use "Salvar como" → .docx).
  • Google Docs: Arquivo → Fazer download → Microsoft Word (.docx) ou OpenDocument (.odt).
  • LibreOffice: o próprio .odt. Pages ou WPS: exportar como Word (.docx).
  • Bloco de Notas, Obsidian e outros editores de texto: .txt ou .md.

O Booksmith procura sozinho as divisões do livro: "Capítulo 1", "Parte 2", Introdução, Apresentação, subcapítulos como "1.1", títulos do Word, linhas em negrito ou com letra maior, e o sumário, se o arquivo tiver um. Antes de criar qualquer capítulo, você revisa e aprova. Linhas só com * * * viram quebras de cena.
